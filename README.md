# ARABIAN LANDMARKS

## Display over 175 landmarks across 22 Arabic countries.

This is a responsive web page built with HTML, CSS, Bootstrap, and JavaScript. When users open the page, they see the top navbar, which has the main logo of the website and has three clickable elements: "Home, Discover, and Contact". When the user clicks on any of them, it will take him to the specific part that matches what he clicked on the page. When the user switches to the mobile view, the navbar will have a toggle button that has the three main elements. In addition, the user will see a welcome message and information about what the website does. The main process is when the user chooses the country, and the page will display the country flag and the country name and up to 10 landmarks of the chosen country with their details. Finally, the user can contact the developer on "Facebook, Instagram, and LinkedIn," which will redirected him to the contact page.

## The tools that I built this project with:

* HTML
* CSS
* Bootstrap
* JavaScript
* Flag CDN (to get the countries' flags and display them)
